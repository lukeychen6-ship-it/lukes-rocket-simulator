A rocket simulator developed by me in Godot.

## Features:
- Building rockets using simple parts
- Fuel system: Required for movement
- Achievements
- Altitude & Position information

## Disclaimers
- This simulator is not a realistic rocket flying simulator, nor is it meant to be.
- This project was partially coded by AI. If you have a problem with that, don't download it. However, I am trying to lower the amount of AI I use in my code and want the simulator to be at least 90% human code.

## Code usage
This is an open-source project, meaning that anyone can see the source code, suggest improvements, and use it for themselves.
